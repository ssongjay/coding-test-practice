## 문제 요약

숫자 문자열 `s`에서 같은 숫자가 세 자리 연속으로 나타나는 부분을 찾아, 그중 가장 큰 값을 **정수**로 반환한다. 해당 부분이 없으면 `-1`, 가장 큰 값이 `000`이면 `0`을 반환한다. 문자열 길이는 0 이상 1,000 미만이다. 원문 전체와 해설은 출처에서 확인한다.

직접 만든 연습 예시:

| 입력 | 반환 |
|---|---|
| `"4555666777"` | `777` |
| `"10002"` | `0` |
| `"121212"` | `-1` |
| `""` | `-1` |

### 정확한 부분

`range(0, len(s) - 2)`는 마지막 시작 인덱스 `len(s) - 3`까지 순회한다. 따라서 `i + 2`가 문자열 범위를 넘지 않는다. 길이가 3보다 짧으면 반복하지 않고 초기값 `-1`을 반환한다.

첫 글자가 두 번째·세 번째 글자와 모두 같은지 확인하므로 연속된 세 숫자가 같은 경우만 후보가 된다. 후보를 정수로 변환해 최댓값을 갱신하며, `int("000")`은 `0`이므로 이 경계도 처리된다. `7777`처럼 후보 구간이 겹치는 경우도 문제없다.

반복마다 고정 길이 3인 문자열을 검사·변환하므로 시간복잡도는 O(n), 추가 공간복잡도는 O(1)이다. `if`가 중첩되어 있어도 내부에 입력 크기에 비례하는 반복이 없으므로 O(n²)이 아니다.

### 작은 개선점

`max`라는 변수명은 Python 내장 함수 `max()`와 이름이 겹친다. 현재 코드에서는 내장 함수를 호출하지 않아 오답 원인은 아니지만, `best` 또는 `largest`로 쓰면 혼동을 피할 수 있다. 세 글자 비교는 `and`로 묶을 수 있고 같은 후보의 정수 변환도 한 번만 할 수 있다. 이는 가독성과 중복 계산 개선이며 시간복잡도는 그대로다.

추천 표현은 아래처럼 별도로 남긴다. 원본 답안은 수정하지 않는다.

<!-- recommended-solution -->
```python
def solution(s):
    best = -1
    for i in range(len(s) - 2):
        if s[i] == s[i + 1] and s[i] == s[i + 2]:
            candidate = int(s[i:i + 3])
            if best < candidate:
                best = candidate
    return best
```

추천 코드도 동일한 로컬 12개 사례를 통과했다. 플랫폼에는 제출하지 않았다.
