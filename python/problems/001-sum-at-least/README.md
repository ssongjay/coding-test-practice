# 001. 기준값 이상인 숫자의 합

## 문제

정수 리스트 `numbers`와 기준값 `limit`가 주어진다. `limit` 이상인 숫자들을 모두 더한 값을 반환한다.

- 같은 값이 여러 번 나오면 각각 더한다.
- 조건에 맞는 숫자가 없거나 빈 리스트라면 0을 반환한다.
- 첫 연습에서는 `sum()` 대신 `for`와 `if`를 사용한다.
- 입력 리스트는 변경하지 않는다.

함수 이름은 `solution(numbers, limit)`이다. 입력을 직접 읽지 않고 전달된 매개변수를 사용하며, 결과를 출력하는 대신 반환한다.

| numbers | limit | 반환값 |
|---|---:|---:|
| `[3, 7, 7, 2]` | 5 | 14 |
| `[1, 2, 3]` | 3 | 3 |
| `[-5, -2, 3]` | -2 | 1 |
| `[]` | 10 | 0 |

## 제한

- 리스트 길이: 0~1,000
- 각 원소와 limit: -1,000~1,000인 정수

## 작성과 확인

`solution.py`의 `NotImplementedError`를 지우고 함수 안을 작성한다. 문법이 기억나지 않으면 먼저 생각나는 형태로 써보고 필요한 부분을 확인한다.

저장소 루트에서 실행한다.

```sh
./practice python 001-sum-at-least run
./practice python 001-sum-at-least check
```

`run.py`는 첫 예제를 실행하고, `check.py`는 여섯 사례와 입력 보존 여부를 확인한다. 답안을 채우기 전에는 두 명령이 미구현 오류로 종료된다.
