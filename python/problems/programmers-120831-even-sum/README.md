# 프로그래머스 120831 — 짝수의 합

- 원문: [짝수의 합](https://school.programmers.co.kr/learn/courses/30/lessons/120831?language=python3)
- 언어: Python 3
- 복습 주제: 반복문·조건문·누적 변수

## 짧은 문제 요약

입력한 정수까지의 범위에서 짝수에 해당하는 값만 합산한다.

전체 조건·제한·공식 예시는 원문에서 확인한다. 이 기록은 다시 찾기 위한 짧은 요약이며 원문 전체를 옮기지 않는다.

## 풀이에서 확인할 것

- `range(n + 1)`은 0부터 n까지 순회한다. 마지막 경계는 포함하지 않으므로 n을 포함하려면 n+1을 전달한다.
- `i % 2 == 0`을 만족하는 값만 누적한다. 0을 더해도 합에는 영향이 없다.
- 반환은 반복이 끝난 뒤 한 번 수행한다.
- 시간복잡도 O(n), 반환값을 제외한 추가 공간 O(1).
