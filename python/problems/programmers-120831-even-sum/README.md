# 프로그래머스 120831 — 짝수의 합

- 원문: [짝수의 합](https://school.programmers.co.kr/learn/courses/30/lessons/120831?language=python3)
- 언어: Python 3
- 복습 주제: 반복문·조건문·누적 변수

## 짧은 문제 요약

입력한 정수까지의 범위에서 짝수에 해당하는 값만 합산한다.

전체 조건·제한·공식 예시는 원문에서 확인한다. 이 기록은 다시 찾기 위한 짧은 요약이며 원문 전체를 옮기지 않는다.

## 풀이와 검증

`solution.py`는 직접 푼 코드를 기록하는 자리다. 아직 정답을 채우지 않았다. `run.py`와 `check.py`의 입력은 로컬 검증용으로 구성했다.

```sh
./practice python programmers-120831-even-sum run
./practice python programmers-120831-even-sum check
```

답안을 작성하기 전에는 미구현 오류로 종료된다. 로컬 사례 통과와 프로그래머스 제출 통과는 따로 기록한다.
