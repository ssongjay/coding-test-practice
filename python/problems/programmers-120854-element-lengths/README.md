## 풀이에서 확인할 것

- `range(len(strlist))`로 유효한 인덱스를 순서대로 순회했다.
- `len(strlist[i])`로 해당 문자열의 길이를 구하고 `append`로 결과에 추가했다.
- 반환은 반복문 밖에서 한 번 수행한다.
- 원소 개수를 m이라 할 때 Python 문자열의 len은 O(1)이므로 시간 O(m), 결과 리스트 공간 O(m)이다.
- 인덱스가 따로 필요하지 않은 경우 `for word in strlist:`로 원소를 직접 순회할 수도 있다. 최초 답안은 그대로 보존한다.

## 복습할 다른 표현

아래는 풀이 후 살펴본 추천 코드다. 내가 제출한 최초 풀이는 `solution.py`에 보존한다.

```python
def solution(strlist):
    answer = []
    for word in strlist:
        answer.append(len(word))
    return answer
```

원래 코드는 인덱스 `i`를 만든 뒤 `strlist[i]`를 꺼낸다. 위 코드는 문자열 자체를 `word`로 받아서 사용한다. 위치 정보가 필요하지 않을 때는 이렇게 직접 순회하면 인덱스 접근을 줄이고 의도를 읽기 쉽게 표현할 수 있다.

두 풀이 모두 시간 O(m), 결과 공간 O(m)이다. 알고리즘 복잡도가 개선된 것은 아니고, 같은 동작을 더 간단히 표현하는 선택이다. 위치가 필요하면 인덱스 순회나 `enumerate`를 사용할 수 있다.

추천 코드는 기존 로컬 검증 5개 사례에서 확인했다. 이 대체 코드로 프로그래머스에 별도 제출하지는 않았다.

다음 복습에서는 같은 리스트를 두 방식으로 순회하고, 각 반복문의 변수가 인덱스인지 원소인지 설명해본다.
