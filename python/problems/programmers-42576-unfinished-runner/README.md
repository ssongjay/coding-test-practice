## 짧은 문제 요약

참가 명단과 완주 명단을 대조해 완주 기록이 없는 한 사람의 이름을 찾는다. 이름이 같은 참가자도 구분해 처리해야 한다.

전체 조건·제한·공식 예시는 원문에서 읽는다. 이 기록은 짧은 자체 요약이다. 이전 문제보다 입력 크기와 중복 조건에 주의하며 접근 방법을 먼저 생각한다.
